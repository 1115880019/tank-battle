# 坦克大战 · Battle City

一个用纯 HTML5 + Canvas 实现的经典《坦克大战》网页游戏。**单文件、零依赖**，浏览器直接打开即可游玩。

## 🎮 试玩

直接打开 `index.html`，按回车或点击「开始游戏」。

## 🕹 操作

| 按键 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` 或 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 |
| `回车` | 开始 / 重新开始 |

移动端会自动显示触屏虚拟按键（方向键 + 开火）。

## ✨ 特性

- **4 种敌方坦克**：普通、快速、火力、装甲（装甲需 4 发）
- **地形**：可破坏的砖墙、不可破坏的钢墙、可阻挡坦克的河流、可藏身的草丛
- **6 种道具**：火力 ★、全灭 💣、加命 ❤、护盾 🛡、加固 🧱、冻结 ⏱
- **3 张地图**，通关后难度提升、无限循环
- **音效**（Web Audio 合成）、粒子爆炸特效、护盾/生成闪烁动画
- **本地最高分**记录（localStorage）
- 支持键盘与触屏

## 🎯 目标

消灭全部 20 辆敌方坦克并**守住基地（老鹰）**。基地被摧毁或生命耗尽即游戏失败。

## 🚀 部署到 GitHub Pages

1. 将仓库推送到 GitHub
2. 进入仓库 **Settings → Pages**
3. Source 选择 `main` 分支、根目录 `/ (root)`
4. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 在线游玩
